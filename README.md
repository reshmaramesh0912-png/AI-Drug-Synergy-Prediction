# 💊 AI-Based Drug Combination Synergy Prediction
A Machine Learning project that predicts whether a drug combination is **synergistic** or **non-synergistic** using the **DrugComb** dataset.

## 📌 Overview
This project demonstrates an end-to-end AI workflow for drug synergy prediction, including data preprocessing, exploratory data analysis (EDA), model training, evaluation, and explainable AI using SHAP.

## 🚀 Workflow
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Correlation Analysis
- Feature Selection
- Random Forest Classification
- Model Evaluation
- SHAP Explainability

## 📊 Model Performance
- **Model:** Random Forest Classifier
- **Accuracy:** 96.5%
- **Precision:** 72%
- **Recall:** 67%
- **F1-Score:** 69%
